# Kambhampati Was Right, and My Compiler Agrees

**Paper:** Kambhampati, Valmeekam, Guan, Verma, Stechly, Bhambri, Saldyt, Murthy (2024). *LLMs Can't Plan, But Can Help Planning in LLM-Modulo Frameworks*. arXiv:2402.01817.

*Chapter in progress — the article version is scheduled.*

LLM-Modulo's architecture: the model generates, sound critics verify, the loop is bounded. It runs today as the planner machine.

**Claim under test.** Sound verifiers make LLM planning honest. The practical discovery is that for code the sound critics are free — vet, build, and test were sitting there all along.
