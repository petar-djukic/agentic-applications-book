# The Best Agent-Safety Paper Is From 1987

**Papers:** Garcia-Molina, Salem (1987). *Sagas*. SIGMOD 1987. Modern bookend: Chang et al. (2025). *SagaLLM: Transaction Guarantees for Multi-Agent LLM Planning*. arXiv:2503.11951.

*Chapter in progress — the article version is scheduled.*

Compensating actions for long-lived transactions were specified almost forty years before anyone let a language model run `helm upgrade`.

**Claim under test.** An agent that changes the world needs a compensating action per step and a distinct outcome for "we tried, it failed, we put it back." The machine version declares the undo on the tool itself.
