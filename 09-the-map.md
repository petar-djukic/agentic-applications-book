# The Map: CoALA With a File Path in Every Box

**Paper:** Sumers, Yao, Narasimhan, Griffiths (2023). *Cognitive
Architectures for Language Agents*. arXiv:2309.02427.

*Chapter in progress — the article version is scheduled.*

CoALA gave agent research a shared vocabulary: memory (working,
episodic, semantic, procedural), actions split into internal and
external, and a decision procedure that selects among them. It is the
closest thing the field has to a common map, and it stays abstract.

This chapter puts a file path in every box. Each CoALA concept is
located in one repository of declarative machines — what holds working
memory, where episodic memory is written, which declaration is a
procedural memory, and what the decision procedure looks like when it is
a state machine rather than a prompt. A reader who finishes this chapter
can read any later chapter's YAML and know which part of the taxonomy
they are looking at.

**Claim under test.** A general cognitive architecture is worth having
only if a concrete system can be laid over it without leftovers. The
rebuild reports what mapped cleanly and what did not.
