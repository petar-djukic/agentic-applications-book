# Ask Every Model, Then Ask One More

**Paper:** Wang, Wang, Athiwaratkun, Zhang, Zou (2024). *Mixture-of-Agents Enhances Large Language Model Capabilities*. arXiv:2406.04692.

*Chapter in progress — the article version is gated on the runtime addition.*

Mixture-of-agents is routing's fan-out sibling: instead of choosing a model, query all of them and synthesize.

**Claim under test.** The change from routing to aggregation is legible as a machine diff, which makes the cost/quality trade the papers argue about into something you can toggle and measure.
